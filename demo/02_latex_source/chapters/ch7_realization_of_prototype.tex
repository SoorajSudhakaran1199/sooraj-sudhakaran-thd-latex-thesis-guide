\section{Prototype record}
\label{sec:prototype}
No physical prototype was built for this demonstration. In a real thesis this
section would identify the realized configuration and deviations from the design.
An assembly record would state component versions and relevant instruments.

\section{Measurement plan}
The fictional plan uses three observations per concept under identical assumed
conditions. A real protocol would define the timing event, operator procedure,
calibration, environmental conditions and measurement uncertainty. Invented data
must never be relabelled as measurements. The demonstration data are kept in a
machine-readable file as well as in Table~\ref{tab:results}.
