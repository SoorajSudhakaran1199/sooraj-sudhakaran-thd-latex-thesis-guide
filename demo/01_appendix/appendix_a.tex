\section{AI usage record format}
For actual permitted AI assistance, record tool name, exact model, date, purpose,
verbatim prompt and any supplied file or public source. Preserve prompts as text,
not screenshots. Do not upload confidential or personal material.

Fictional format example: Tool: [tool]; Model: [model]; Date: [date];
Purpose: spelling review; Prompt: ``Identify spelling errors in this sentence.'';
Supplied files: none. This is a format example, not an actual usage log.
